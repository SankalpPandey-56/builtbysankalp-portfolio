# BuiltbySANKALP — Portfolio

A personal portfolio for Sankalp (BuiltbySANKALP), built with React, Vite, TypeScript, Tailwind CSS v4, and Motion.

## ✨ Features

- **Studio-Lumio-style hero** — huge "SANKALP PANDEY" typography that rolls character-by-character on hover
- **Custom morphing cursor** — a dot that becomes a ring over links and a "More +" pill over the photo
- **Genuine story** — honest about being a first-year student learning HTML/CSS/Python, with AI & prompt engineering as a core strength
- **GitHub projects** — real repos pulled from [github.com/SankalpPandey-56](https://github.com/SankalpPandey-56)
- **Education timeline** — scroll-linked growing line with alternating cards
- **Extras** — scroll progress bar, magnetic buttons, spotlight photo, expandable toolbar dock

## 🛠️ Tech Stack

- [Vite](https://vitejs.dev/) + [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Motion](https://motion.dev/)
- [lucide-react](https://lucide.dev/) icons

## 🚀 Getting Started

```bash
npm install
npm run dev      # local dev server at http://localhost:5173
npm run build    # production build into dist/
npm run preview  # preview the production build
```

## 📦 Deploy

The site is deployed to GitHub Pages at
[https://sankalppandey-56.github.io/builtbysankalp/](https://sankalppandey-56.github.io/builtbysankalp/)
by building (`npm run build`) and pushing the `dist/` contents to the `builtbysankalp` repo.

## 📷 Photo

Drop your real photo at `public/photo.jpg` — it's referenced from `data/site.ts` via `site.photo`.
